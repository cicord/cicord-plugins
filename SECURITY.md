# Security

Report a vulnerability in a plugin of this registry, in the registry tooling or in its
signing, privately through GitHub's *Report a vulnerability* (Security tab of this
repository), or as described in the
[Cicord security policy](https://github.com/cicord/cicord/blob/main/SECURITY.md). Do not open a
public issue.

Plugins with a serious unfixed issue are removed from `index.yaml` and the index is signed
again; the fix is released as a new version.
